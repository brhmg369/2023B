# 写给论文手：问题一建模交接

本文档只服务于 2023 年 B 题问题一正文写作。目标是让论文手可以直接据此写“问题分析、模型建立、模型求解、结果表和模型检验”，不要把这里的内部说明原样复制进论文。

## 一、题意拆分

问题一给定一个二维剖面：测线方向垂直的平面与海底坡面相交成一条斜线，斜线与水平面夹角为坡度 `alpha`。多波束换能器的开角为 `theta`，海域中心点水深为 `D0`，要求建立：

1. 任意测线位置处的水深模型；
2. 该位置多波束条带覆盖宽度模型；
3. 相邻两条测线之间的重叠率模型；
4. 在 `theta = 120 deg`、`alpha = 1.5 deg`、`D0 = 70 m`、测线距中心点为 `-800,-600,...,800 m` 时计算表 1。

该问没有随机数据、没有优化决策，也没有拟合参数，主问题类型是二维几何建模和公式计算。

## 二、算法选择

选择解析几何/三角函数模型，不使用机器学习或智能优化。

理由：

1. 题面几何结构完整，所有参数由题目给定；
2. 输出是确定性指标，不需要训练或搜索；
3. 优秀案例卡 `case-105`、`case-106`、`case-107` 对 2023B 的迁移经验均把问题一作为二维覆盖宽度和重叠率几何模型处理；
4. 几何模型可解释、可复算，并且能自然推广到问题二、三、四。

## 三、符号约定

| 符号 | 含义 | 单位 |
|---|---|---|
| `x` | 测线距海域中心点的水平距离，正方向取为浅水上坡方向 | m |
| `D0` | 海域中心点水深 | m |
| `D(x)` | 位置 `x` 处的海水深度 | m |
| `alpha` | 海底坡面与水平面的夹角 | rad 或 deg |
| `theta` | 多波束换能器开角 | rad 或 deg |
| `phi` | 半开角，`phi = theta / 2` | rad 或 deg |
| `B_L(x)` | 测线左侧半覆盖宽度的水平投影 | m |
| `B_R(x)` | 测线右侧半覆盖宽度的水平投影 | m |
| `W(x)` | 总覆盖宽度的水平投影 | m |
| `eta_i` | 第 `i` 条测线与前一条测线的重叠率 | % |

## 四、重要公式

水深随水平位置线性变化：

```text
D(x) = D0 - x tan(alpha)
```

其中 `x > 0` 表示向浅水侧移动，所以深度减小。

由正弦定理或射线与坡面交点几何关系，可得两侧半覆盖宽度：

```text
B_L(x) = D(x) sin(phi) cos(alpha) / cos(phi + alpha)
B_R(x) = D(x) sin(phi) cos(alpha) / cos(phi - alpha)
```

覆盖宽度：

```text
W(x) = B_L(x) + B_R(x)
     = D(x) sin(phi) cos(alpha)
       [1/cos(phi + alpha) + 1/cos(phi - alpha)]
```

若第 `i-1` 条测线和第 `i` 条测线的水平间距为 `d_i = x_i - x_{i-1}`，相邻条带的重叠宽度取两条带相交的水平宽度：

```text
O_i = B_R(x_{i-1}) + B_L(x_i) - d_i
```

重叠率采用“相对当前条带宽度”的口径：

```text
eta_i = O_i / W(x_i)
```

当 `O_i < 0` 或 `eta_i < 0` 时，表示两条带之间存在漏测。

平底退化检验：当 `alpha = 0` 时，

```text
B_L = B_R = D tan(theta/2)
W = 2D tan(theta/2)
eta = 1 - d/W
```

说明模型与题面给出的平坦海底公式一致。

## 五、求解过程

1. 输入题目参数：`theta = 120 deg`，`alpha = 1.5 deg`，`D0 = 70 m`。
2. 对表 1 的每个位置 `x`，计算 `D(x)`。
3. 用半覆盖宽度公式计算 `B_L(x)`、`B_R(x)`。
4. 求 `W(x) = B_L(x) + B_R(x)`。
5. 从第二条测线开始，用前一条测线的右半宽和当前测线的左半宽计算重叠宽度 `O_i`，再求 `eta_i`。
6. 保留两位小数，写入 `result1.xlsx`。

## 七、写作建议

正文中建议把本问写成“测深几何剖面模型”，不要称为优化模型。重叠率公式要特别说明使用左右半宽相交法，因为斜坡会导致左右半宽不对称；这样比直接套 `1-d/W` 更严谨。

可在“模型检验”中写两点：

1. 当 `alpha = 0` 时，模型退化为平坦海底公式 `W = 2D tan(theta/2)` 和 `eta = 1-d/W`；
2. 随 `x` 从 `-800 m` 增至 `800 m`，水深和覆盖宽度单调减小，符合“浅水处覆盖宽度较小，更容易漏测”的物理直觉。
