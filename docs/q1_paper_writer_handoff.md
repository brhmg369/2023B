# 写给论文手：问题一建模交接

本文档只服务于 2023 年 B 题问题一正文写作。目标是让论文手可以直接据此写“问题分析、模型建立、模型求解、结果表和模型检验”，不要把这里的内部说明原样复制进论文。

## 一、题意拆分

问题一给定一个二维剖面：测线方向垂直的平面与海底坡面相交成一条斜线，斜线与水平面夹角为坡度 `alpha`。多波束换能器的开角为 `theta`，海域中心点水深为 `D0`，要求建立：

1. 任意测线位置处的水深模型；
2. 该位置多波束条带覆盖宽度模型；
3. 相邻两条测线之间的重叠率模型；
4. 在 `theta = 120 deg`、`alpha = 1.5 deg`、`D0 = 70 m`、测线距中心点为 `-800,-600,...,800 m` 时计算表 1。

该问没有随机数据、没有优化决策，也没有拟合参数，主问题类型是二维几何建模和公式计算。

## 二、算法选择

选择解析几何/三角函数模型，不使用机器学习或智能优化。

理由：

1. 题面几何结构完整，所有参数由题目给定；
2. 输出是确定性指标，不需要训练或搜索；
3. 优秀案例卡 `case-105`、`case-106`、`case-107` 对 2023B 的迁移经验均把问题一作为二维覆盖宽度和重叠率几何模型处理；
4. 几何模型可解释、可复算，并且能自然推广到问题二、三、四。

## 三、符号约定

| 符号 | 含义 | 单位 |
|---|---|---|
| `x` | 测线距海域中心点的水平距离，正方向取为浅水上坡方向 | m |
| `D0` | 海域中心点水深 | m |
| `D(x)` | 位置 `x` 处的海水深度 | m |
| `alpha` | 海底坡面与水平面的夹角 | rad 或 deg |
| `theta` | 多波束换能器开角 | rad 或 deg |
| `phi` | 半开角，`phi = theta / 2` | rad 或 deg |
| `B_L(x)` | 测线左侧半覆盖宽度的水平投影 | m |
| `B_R(x)` | 测线右侧半覆盖宽度的水平投影 | m |
| `W(x)` | 总覆盖宽度的水平投影 | m |
| `eta_i` | 第 `i` 条测线与前一条测线的重叠率 | % |

## 四、核心口径（论文务必统一）

第一问最容易出错的地方不是三角公式，而是宽度和重叠率的口径。正文、表 1、代码和摘要中的相关表述必须保持以下定义。

1. 坐标口径：以海域中心点为原点，在与测线方向垂直的二维剖面内建立水平坐标 `x`；`x > 0` 取向浅水上坡方向，`x < 0` 取向深水下坡方向。表 1 的列按 `-800,-600,...,800 m` 排列，因此从左到右水深递减。
2. 水深口径：`D(x)` 是测线所在位置的垂直水深，不是沿声束方向的斜距，也不是沿海底坡面的距离。
3. 覆盖宽度 `W` 的口径：`W(x)` 是单条测线在该位置形成的全覆盖条带宽度在水平面上的横向投影，方向垂直于测线方向。它等于左、右两个半覆盖宽度的水平投影之和，即 `W(x)=B_L(x)+B_R(x)`。它不是海底斜面上的弧长/坡面长度，也不是某一侧半宽。
4. 测线间距 `d_i` 的口径：`d_i=x_i-x_{i-1}` 是相邻两条平行测线在同一水平剖面上的水平距离，与 `W`、`B_L`、`B_R` 使用同一量纲口径，不能用坡面距离代替。
5. 重叠宽度 `O_i` 的口径：第 `i` 列的“与前一条测线的重叠率”先计算第 `i-1` 条测线右侧半宽与第 `i` 条测线左侧半宽在水平面上的相交宽度，
   `O_i=B_R(x_{i-1})+B_L(x_i)-d_i`。这里保留代数符号，不做 `max(O_i,0)` 截断；若 `O_i<0`，表示两条带之间出现漏测，漏测间隙宽度为 `-O_i`。
6. 重叠率 `eta_i` 的口径：本程序和 `result1.xlsx` 采用“相对于当前测线条带覆盖宽度”的定义，
   `eta_i=O_i/W(x_i)`，结果以百分数表示。第一列没有前一条测线，因此记为 `--`。若改用前一条条带宽度或两条带平均宽度作分母，斜坡情形下数值会改变，论文中不要混用。
7. 平底公式口径：题面给出的 `eta=1-d/W` 是平坦海底、相邻条带宽度相同的特例。斜坡情形下左右半宽不对称，应先算 `O_i` 再除以当前条带宽度；当 `alpha=0` 时，上述定义自动退化为题面平底公式。

一句话给论文手：第一问的 `W` 是“当前测线条带在水平面上的总覆盖宽度”，`eta_i` 是“当前测线与前一条测线的代数重叠宽度除以当前测线覆盖宽度”。

## 五、重要公式

水深随水平位置线性变化：

```text
D(x) = D0 - x tan(alpha)
```

其中 `x > 0` 表示向浅水侧移动，所以深度减小。

由正弦定理或射线与坡面交点几何关系，可得两侧半覆盖宽度：

```text
B_L(x) = D(x) sin(phi) cos(alpha) / cos(phi + alpha)
B_R(x) = D(x) sin(phi) cos(alpha) / cos(phi - alpha)
```

覆盖宽度：

```text
W(x) = B_L(x) + B_R(x)
     = D(x) sin(phi) cos(alpha)
       [1/cos(phi + alpha) + 1/cos(phi - alpha)]
```

若第 `i-1` 条测线和第 `i` 条测线的水平间距为 `d_i = x_i - x_{i-1}`，相邻条带的重叠宽度取两条带相交的水平宽度：

```text
O_i = B_R(x_{i-1}) + B_L(x_i) - d_i
```

重叠率采用“相对当前条带宽度”的口径，并保留负值来表示漏测：

```text
eta_i = O_i / W(x_i) * 100%
```

当 `O_i < 0` 或 `eta_i < 0` 时，表示两条带之间存在漏测。

平底退化检验：当 `alpha = 0` 时，

```text
B_L = B_R = D tan(theta/2)
W = 2D tan(theta/2)
eta = 1 - d/W
```

说明模型与题面给出的平坦海底公式一致。

## 六、求解过程

1. 输入题目参数：`theta = 120 deg`，`alpha = 1.5 deg`，`D0 = 70 m`。
2. 对表 1 的每个位置 `x`，计算 `D(x)`。
3. 用半覆盖宽度公式计算 `B_L(x)`、`B_R(x)`。
4. 求 `W(x) = B_L(x) + B_R(x)`。
5. 从第二条测线开始，用前一条测线的右半宽和当前测线的左半宽计算重叠宽度 `O_i`，再求 `eta_i`。
6. 保留两位小数，写入 `result1.xlsx`。

## 八、写作建议

正文中建议把本问写成“测深几何剖面模型”，不要称为优化模型。重叠率公式要特别说明使用左右半宽相交法，因为斜坡会导致左右半宽不对称；这样比直接套 `1-d/W` 更严谨。

可在“模型检验”中写两点：

1. 当 `alpha = 0` 时，模型退化为平坦海底公式 `W = 2D tan(theta/2)` 和 `eta = 1-d/W`；
2. 随 `x` 从 `-800 m` 增至 `800 m`，水深和覆盖宽度单调减小，符合“浅水处覆盖宽度较小，更容易漏测”的物理直觉。

## 九、建议论文手绘图和制表的位置

你不需要在建模程序里额外生成这些图表，但论文手可以尽量多用图表把第一问讲清楚。推荐如下：

1. 二维几何口径示意图：画出水平轴 `x`、海底斜线、中心点水深 `D0`、当前位置水深 `D(x)`、坡度 `alpha`、开角 `theta`、左右半覆盖宽度 `B_L`、`B_R` 和总宽度 `W`。这张图放在“问题分析/模型建立”最合适。
2. 覆盖宽度推导图：单独画声束边界与坡面相交的三角形，标注 `phi=theta/2`、`phi+alpha`、`phi-alpha`，用于解释为什么左右半宽分母不同。
3. 相邻条带重叠口径图：画第 `i-1` 条和第 `i` 条测线，标出 `d_i`、`B_R(x_{i-1})`、`B_L(x_i)`、`O_i`，并在旁边注明 `O_i<0` 表示漏测。这张图对避免分母口径错误最重要。
4. 表 1 正式结果表：直接采用 `result1.xlsx` 的“问题1结果”工作表，放正文结果部分。
5. 计算明细表：可从 `result1.xlsx` 的“计算明细”工作表摘录 `B_L`、`B_R`、`O_i` 三列，展示斜坡导致左右半宽不对称。正文篇幅不够时放附录。
6. 水深和覆盖宽度随位置变化曲线：横轴为 `x`，纵轴分别画 `D(x)` 与 `W(x)`，说明浅水侧覆盖宽度变小。可以双纵轴，也可以分成两幅小图。
7. 重叠率随位置变化曲线：横轴为当前测线位置 `x_i`，纵轴为 `eta_i`，并画出题面建议的 `10%~20%` 区间带、`0%` 漏测警戒线。该图能直观看出右侧浅水处开始漏测。
8. 特殊情形检验表：列 `alpha=0` 时的 `B_L=B_R=D tan(theta/2)`、`W=2D tan(theta/2)`、`eta=1-d/W`，与一般公式退化结果对照。
9. 敏感性二维曲线：固定 `theta=120 deg`，分别改变 `alpha` 或 `D0`，观察 `W` 和 `eta` 的变化，用于模型评价部分。
10. 可选三维曲面图：若论文版面允许，可画 `W(D, alpha)` 三维曲面，或画 `eta(d, D)` 三维曲面，展示水深、坡度、测线间距对覆盖宽度/重叠率的联合作用。三维图只作为机理解释或敏感性分析，不替代表 1。

图表写作提醒：每张图都要说明它回答哪个问题。第一问最核心的图是“覆盖宽度推导图”和“相邻条带重叠口径图”；如果篇幅有限，优先保留这两张。
