# 写给论文手：问题三建模交接

本文档只服务于 2023 年 B 题问题三正文写作。目标是让论文手可以直接据此写“问题分析、模型建立、模型求解、结果与检验”，不要把这里的内部说明原样复制进论文。

## 一、题意拆分

问题三给定一个规则矩形海域：

1. 南北长 `2 NM`，东西宽 `4 NM`；
2. 海域中心水深 `D0 = 110 m`；
3. 海底西深东浅，坡度 `alpha = 1.5 deg`；
4. 多波束换能器开角 `theta = 120 deg`；
5. 需要设计总长度最短、完全覆盖整个海域、相邻条带重叠率满足 `10%~20%` 的测线。

该问的输出不是单个覆盖宽度，而是一组测线位置和总长度。主问题类型是“几何约束优化”：用问题一的二维覆盖宽度和重叠率模型作为约束，用测线总长度作为目标。

## 二、算法选择

选择“等深线方向布设 + 一维贪心递推”的解析优化算法。

理由：

1. 海底是单一平面，且西深东浅，等深线为南北向直线；
2. 测线沿等深线方向时，每条测线上的水深恒定，覆盖宽度只随东西坐标 `x` 变化，问题可降为一维布线；
3. 若测线偏离等深线方向，同一测线会跨越深浅变化，浅水端的较小覆盖宽度会限制整条线的有效间距，同时线段在矩形内通常更长，不利于最短总长度；
4. 同题案例 `case-105`、`case-106`、`case-107` 的可迁移经验均是先用几何模型确定覆盖和重叠关系，再用递推或贪心搜索设计测线；
5. 本题数据和约束确定，不需要机器学习；用随机优化反而会降低可解释性。

候选方案可在论文中简要比较：

| 方案 | 思路 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A 平均间距法 | 用中心水深或平均水深给固定间距 | 简单 | 浅水侧容易漏测，深水侧冗余 | 只作基线 |
| B 等深线贪心递推 | 沿南北向布线，每次取满足 10% 重叠的最远下一条线 | 可解释、可证明 34 条内最短 | 只适用于规则坡面 | 本文采用 |
| C 全方向搜索/启发式 | 搜索不同方向和间距 | 可作为扩展 | 本问结构简单，复杂度无必要 | 可放拓展或检验 |

## 三、坐标、符号和核心口径

以矩形海域中心为原点，建立水平坐标系：

| 符号 | 含义 | 单位 |
|---|---|---|
| `x` | 东西向坐标，向东为正，东侧为浅水侧 | m |
| `y` | 南北向坐标，向北为正 | m |
| `x_min,x_max` | 西、东边界，分别为 `-2 NM, 2 NM` | m |
| `y_min,y_max` | 南、北边界，分别为 `-1 NM, 1 NM` | m |
| `D(x)` | 坐标 `x` 处的垂直水深 | m |
| `B_W(x)` | 测线向西侧的水平半覆盖宽度 | m |
| `B_E(x)` | 测线向东侧的水平半覆盖宽度 | m |
| `W_h(x)` | 条带在水平面上的总覆盖宽度，`W_h=B_W+B_E` | m |
| `W_s(x)` | 条带在坡面上的实际覆盖长度，可由 `W_s=W_h/cos(alpha)` 得到 | m |
| `d_i` | 第 `i-1` 条和第 `i` 条测线的水平间距 | m |
| `O_i` | 第 `i-1` 条和第 `i` 条测线的代数重叠宽度 | m |
| `eta_i` | 第 `i` 条测线相对前一条测线的重叠率 | % |

重要口径：

1. 第三问用于布线和重叠率约束的是 `W_h`，即水平投影覆盖宽度。原因是测线间距 `d_i` 是水平布设距离，必须与 `W_h` 同口径比较。
2. 坡面实际覆盖长度 `W_s` 可以在论文中作为概念说明或敏感性补充，但不能拿它直接和水平间距 `d_i` 代入重叠率公式。
3. 重叠率采用与第一问一致的“相对当前测线条带覆盖宽度”口径：`eta_i=O_i/W_h(x_i)`。

## 四、重要公式

海里换算：

```text
1 NM = 1852 m
x_min = -3704 m, x_max = 3704 m
y_min = -1852 m, y_max = 1852 m
```

水深模型：

```text
D(x) = D0 - x tan(alpha)
```

其中 `x>0` 表示向东侧浅水方向移动，所以水深减小。

南北向测线垂直剖面与问题一相同。令 `phi=theta/2`，则两侧水平半覆盖宽度为：

```text
B_W(x) = D(x) sin(phi) cos(alpha) / cos(phi + alpha)
B_E(x) = D(x) sin(phi) cos(alpha) / cos(phi - alpha)
```

水平投影覆盖宽度：

```text
W_h(x) = B_W(x) + B_E(x)
```

第 `i-1` 条和第 `i` 条测线之间的代数重叠宽度：

```text
O_i = B_E(x_{i-1}) + B_W(x_i) - (x_i - x_{i-1})
```

重叠率：

```text
eta_i = O_i / W_h(x_i) * 100%
```

约束条件：

```text
x_1 - B_W(x_1) <= x_min
x_n + B_E(x_n) >= x_max
10% <= eta_i <= 20%, i=2,...,n
```

目标函数：

```text
min L_total = n (y_max - y_min)
```

因为测线均为南北向且贯穿矩形，每条线长度为 `2 NM = 3704 m`，所以最小化总长度等价于最小化测线条数 `n`。

## 五、求解过程

1. 先确定测线方向：沿等深线南北向布设。
2. 将第一条测线尽可能向东放置，同时保证其西侧覆盖边界刚好覆盖西边界，即求解：

```text
x_1 - B_W(x_1) = x_min
```

3. 从第 `i-1` 条线递推第 `i` 条线。为了最小化测线数，应让每一步水平间距尽可能大，因此取重叠率下限：

```text
eta_i = 10%
```

4. 继续递推，直到末条线满足：

```text
x_n + B_E(x_n) >= x_max
```

5. 对所有相邻测线复算 `eta_i`，检查是否在 `10%~20%` 范围内。
6. 用少一条测线的递推结果检查是否仍有东侧缺口，从而说明当前条数在该测线方向下不可再减少。

## 七、模型检验与结果解释

建议论文中至少写以下四项检验：

1. 完全覆盖检验：首条测线西侧边界为 `-3704.00 m`，正好覆盖西边界；末条测线东侧边界为 `3719.41 m`，超过东边界 `3704.00 m`，因此东西方向无漏测。
2. 重叠率检验：程序逐对复算 33 个相邻重叠率，均为 `10.00%`，满足 `10%~20%`。
3. 最小条数检验：若少一条测线，在保持每一步取最大可行间距的情况下，最东覆盖边界只能到 `3678.24 m`，距东边界仍有 `25.76 m` 缺口，因此 33 条不可行。
4. 物理合理性检验：由西向东水深减小，覆盖宽度随之减小，因此测线间距也逐渐缩小，符合浅水区需要更密测线的直觉。
