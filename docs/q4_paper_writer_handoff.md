# 写给论文手：问题四建模交接

本文档只服务于 2023 年 B 题问题四正文写作。目标是让论文手可以直接据此写“数据处理、模型建立、模型求解、结果分析、模型检验和图表展示建议”，不要把这里的内部说明原样复制进论文。

## 一、题意拆分

问题四给出某海域若干年前的单波束测深数据，海域南北长 `5 NM`、东西宽 `4 NM`，附件横纵坐标单位为海里，水深单位为米。要求利用该数据为多波束测量船设计测线，并计算：

1. 测线总长度；
2. 漏测海区占总待测海域面积的百分比；
3. 在重叠区域中，重叠率超过 `20%` 部分的总长度。

本问不是单纯套第三问规则坡面，而是“数据驱动的海底曲面重建 + 几何覆盖评价 + 多目标布线优化”。三个目标有优先关系：先尽量覆盖，再控制超 20% 重叠，最后压缩测线总长度。

## 二、数据审计

程序读取 `附件.xlsx` 后得到：

```text
横向坐标：0 到 4 NM，步长 0.02 NM，共 201 个点
纵向坐标：0 到 5 NM，步长 0.02 NM，共 251 个点
水深点数：50451
缺失值：0
水深范围：20.00 m 到 197.20 m
平均水深：62.54 m
```

数据是规则网格，因此无需插值成新网格；程序在原始网格上估计局部坡度并复算覆盖情况。

## 三、算法选择

选择“局部坡度几何模型 + 南北向分带递推布线 + 网格覆盖仿真评价”。

候选方案比较：

| 方案 | 分带高度 | 线段数 | 总长度/m | 漏测率/% | 超 20% 重叠长度/m | 说明 |
|---|---:|---:|---:|---:|---:|---|
| 全域统一布线 | 5.0 NM | 60 | 555600.00 | 0.0000 | 276877.69 | 线段少，但深浅差异导致重叠冗余很大 |
| 1.0 NM 分带 | 1.0 NM | 240 | 444480.00 | 0.0000 | 51525.55 | 明显降低总长度和冗余 |
| 0.5 NM 分带（主推荐） | 0.5 NM | 461 | 426886.00 | 0.0000 | 5481.92 | 长度、冗余和可执行性较平衡 |
| 0.25 NM 分带 | 0.25 NM | 897 | 415311.00 | 0.0000 | 2742.38 | 表内指标更短，但线段数接近翻倍 |

主推荐采用 `0.5 NM` 分带。理由是：若只按题面三个数值指标，`0.25 NM` 候选更激进；但它把测线切得更碎，会带来大量转场和调头成本，而题面指标没有计入这部分现实代价。`0.5 NM` 方案在漏测率为 0 的前提下，把超 20% 重叠长度压到约 `5.48 km`，同时线段数仍较可解释。论文中可把 `0.25 NM` 作为“更短但更碎”的对照方案。

## 四、符号和核心口径

| 符号 | 含义 | 单位 |
|---|---|---|
| `x,y` | 附件中的东西向、南北向水平坐标 | NM 或 m |
| `D(x,y)` | 水深，正值表示向下 | m |
| `g_x` | 东西向局部水深梯度，`g_x = partial D / partial x` | m/m |
| `theta` | 多波束换能器开角，题面取 `120 deg` | deg |
| `phi` | 半开角，`phi = theta / 2` | deg |
| `B_W(x,y)` | 南北向测线在点 `(x,y)` 处向西侧的水平半覆盖宽度 | m |
| `B_E(x,y)` | 南北向测线在点 `(x,y)` 处向东侧的水平半覆盖宽度 | m |
| `W_h(x,y)` | 水平投影覆盖宽度，`W_h=B_W+B_E` | m |
| `O_i(y)` | 同一分带内相邻测线在纵向位置 `y` 的代数重叠宽度 | m |
| `eta_i(y)` | 同一分带内相邻测线在纵向位置 `y` 的重叠率 | % |

重要口径：

1. 第四问用于布线和面积评价的是水平投影覆盖宽度 `W_h`，与水平坐标、水平面积和测线间距同口径。
2. 附件水深是正值，表示从海面向下的垂直深度。
3. 超 20% 重叠长度按相邻测线对逐段累计：若某一相邻测线对在某些 `y` 位置满足 `eta_i(y)>20%`，则把这些纵向长度计入总长度。

## 五、重要公式

坐标换算：

```text
x_m = 1852 x_NM
y_m = 1852 y_NM
```

局部东西向坡度用中心差分估计：

```text
g_x(x,y) = partial D(x,y) / partial x
```

对南北向测线，多波束扫描剖面沿东西方向。将局部海底剖面近似为：

```text
D(x+u,y) = D(x,y) + g_x(x,y) u
```

声束边界与局部线性海底相交，可得两侧水平半覆盖宽度：

```text
B_W(x,y) = D(x,y) / [cot(phi) + g_x(x,y)]
B_E(x,y) = D(x,y) / [cot(phi) - g_x(x,y)]
W_h(x,y) = B_W(x,y) + B_E(x,y)
```

相邻两条测线 `x_i < x_{i+1}` 在同一 `y` 位置的重叠宽度：

```text
O_i(y) = B_E(x_i,y) + B_W(x_{i+1},y) - (x_{i+1}-x_i)
```

重叠率：

```text
eta_i(y) = O_i(y) / W_h(x_{i+1},y) * 100%
```

覆盖判定：

```text
点 (x,y) 被第 i 条测线覆盖
<=> x_i - B_W(x_i,y) <= x <= x_i + B_E(x_i,y)
```

漏测率用原始网格点近似面积比例：

```text
漏测率 = 未被任何测线覆盖的网格点数 / 总网格点数 * 100%
```

## 六、求解过程

1. 读取附件，得到规则水深网格和坐标轴。
2. 用差分估计 `g_x`，因为主方案采用南北向测线，覆盖宽度主要受东西向剖面坡度影响。
3. 将海域按南北方向分成 10 个水平带，每带高度 `0.5 NM`。
4. 在每个分带内用递推法布设南北向线段：

```text
第 1 条线：取尽可能靠东的位置，同时保证西边界被覆盖
max_y [x_1 - B_W(x_1,y)] <= x_min

第 i+1 条线：取尽可能靠东的位置，同时保证与前一条线之间无漏测
min_y [B_E(x_i,y) + B_W(x_{i+1},y) - (x_{i+1}-x_i)] >= 0

终止条件：末条线覆盖东边界
min_y [x_n + B_E(x_n,y)] >= x_max
```

5. 将所有分带线段合并，得到推荐测线方案。
6. 在原始 `201 x 251` 网格上逐点复算覆盖情况，计算漏测率。
7. 对每个分带内相邻测线对逐 `y` 复算 `eta_i(y)`，统计 `eta_i(y)>20%` 的纵向长度。

## 八、模型检验与结果解释

建议论文中写以下检验：

1. 数据完整性检验：附件网格为 `201 x 251`，无缺失，坐标范围与题面 `4 NM x 5 NM` 一致。
2. 覆盖率检验：推荐方案在原始网格上复算，漏测率为 `0.0000%`。
3. 重叠率检验：虽然局部最大相邻重叠率达到 `49.01%`，但超 20% 部分总长度仅 `5481.92 m`，相对于 `426886.00 m` 总测线长度占比较小。
4. 分带敏感性：由全域统一布线到 0.5 NM 分带，总长度从 `555600.00 m` 降至 `426886.00 m`，超 20% 重叠长度从 `276877.69 m` 降至 `5481.92 m`，说明分带策略有效。
5. 方案取舍：0.25 NM 分带进一步降低表内总长度，但线段数从 461 增至 897，论文需说明是否接受更高执行复杂度。

## 十一、注意事项

1. 本方案只统计测量线段长度，没有计入不同线段之间的转场、调头和航行连接成本。
2. 主推荐 `0.5 NM` 分带是兼顾三项题面指标和现实可执行性的折中；若论文队决定完全不考虑线段数量和转场复杂度，可把 `0.25 NM` 方案作为最终方案。
3. `W_h` 仍是水平投影覆盖宽度，用于面积、间距和重叠率计算；不要与坡面实际长度混用。
4. 案例库只作为内部建模决策参考，不要在正文声称本公式或参数来自某篇优秀论文。
