# 写给论文手：问题二建模交接

本文档只服务于 2023 年 B 题问题二正文写作。目标是让论文手可以直接据此写“问题分析、模型建立、模型求解、结果表和模型检验”，不要把这里的内部说明原样复制进论文。

## 一、题意拆分

问题二把问题一的二维坡面剖面推广到三维矩形海域。已知：

1. 多波束换能器开角 `theta = 120 deg`；
2. 海底坡度 `alpha = 1.5 deg`；
3. 海域中心点水深 `D0 = 120 m`；
4. 测线方向与海底坡面法向在水平面上的投影夹角为 `beta`；
5. 需要计算测量船距海域中心点 `0,0.3,...,2.1 NM` 时的覆盖宽度。

本问需要输出表 2 中不同 `beta` 和不同距离组合下的覆盖宽度。它没有拟合数据、没有最优化目标，主问题类型是三维几何建模和确定性公式计算。

## 二、算法选择

选择“空间几何投影 + 问题一二维覆盖宽度公式”的解析模型。

理由：

1. 问题一已经建立了斜坡剖面上的覆盖宽度模型；
2. 问题二的测线方向只改变两个量：船位处水深、垂直测线剖面中的等效坡度；
3. 同题案例 `case-105`、`case-106`、`case-107` 均把问题二作为三维坡面几何推广处理，尤其强调由向量/线面角将三维问题转化为二维剖面问题；
4. 不需要优化算法或机器学习，解析公式更可解释、更易复算。

## 三、符号约定

| 符号 | 含义 | 单位 |
|---|---|---|
| `r` | 测量船距海域中心点的距离 | NM 或 m |
| `D0` | 海域中心点水深 | m |
| `D(r,beta)` | 船位处水深 | m |
| `alpha` | 海底坡度 | rad 或 deg |
| `theta` | 多波束换能器开角 | rad 或 deg |
| `phi` | 半开角，`phi = theta / 2` | rad 或 deg |
| `beta` | 测线方向与坡面法向水平投影的夹角 | rad 或 deg |
| `alpha_eff` | 垂直测线剖面中的等效坡度 | rad 或 deg |
| `W(r,beta)` | 覆盖宽度 | m |

方向约定：将坡面法向在水平面上的投影正方向取为深水方向。因此船从中心沿 `beta=0` 前进时水深增大；沿 `beta=180 deg` 前进时水深减小；沿 `beta=90 deg` 或 `270 deg` 前进时沿等深线方向运动，水深保持为 `D0`。

## 四、重要公式

距离单位换算：

```text
s = 1852 r
```

船位处水深：

```text
D(r,beta) = D0 + s tan(alpha) cos(beta)
```

其中 `s` 以米为单位。

因为多波束扫描所在平面垂直于测线方向，真正影响覆盖宽度的是坡度在该垂直剖面方向上的分量。等效坡度满足：

```text
tan(alpha_eff) = tan(alpha) sin(beta)
alpha_eff = arctan[tan(alpha) sin(beta)]
```

将问题一公式中的坡度替换为 `alpha_eff`，得到覆盖宽度：

```text
W(r,beta) =
D(r,beta) sin(phi) cos(alpha_eff)
[1/cos(phi + alpha_eff) + 1/cos(phi - alpha_eff)]
```

等价写法：

```text
W(r,beta) =
2 D(r,beta) sin(theta) cos^2(alpha_eff)
/ [cos(theta) + cos(2 alpha_eff)]
```

两种写法数值相同；正文建议使用第一种，因为它直接承接问题一的左右半宽模型。

## 五、求解过程

1. 输入题目参数：`theta = 120 deg`，`alpha = 1.5 deg`，`D0 = 120 m`。
2. 对每个 `beta` 和每个距离 `r`，先将 `r` 从海里换算为米。
3. 用 `D(r,beta)` 计算船位水深。
4. 用 `alpha_eff = arctan[tan(alpha) sin(beta)]` 计算垂直测线剖面中的等效坡度。
5. 将 `D(r,beta)` 和 `alpha_eff` 代入覆盖宽度公式。
6. 保留两位小数，写入 `result2.xlsx`。

## 七、模型检验与结果解释

建议正文写以下检验：

1. 当 `beta = 0 deg` 或 `180 deg` 时，测线方向沿坡面法向水平投影，垂直测线剖面近似沿等深线方向，故 `alpha_eff = 0`，公式退化为平底公式 `W = 2D tan(theta/2)`。
2. 当 `beta = 90 deg` 或 `270 deg` 时，测量船沿等深线方向运动，所以 `D(r,beta) = D0`，表中该两行覆盖宽度不随距离变化。
3. `beta` 与 `360 deg - beta` 在等效坡度绝对值上相同，但由于水深随 `cos(beta)` 改变，覆盖宽度会体现深浅方向差异。
4. 覆盖宽度随水深增大而增大，`beta=0` 行随距离增加显著增大，`beta=180` 行随距离增加显著减小，符合物理直觉。

## 九、建议论文手绘图和制表的位置

这里不由建模手额外生成图片或论文排版表，但建议论文手尽量多用图表展示几何关系和数值规律：

1. **三维坡面与测线方向示意图**：在问题二模型建立前画，展示水平面、海底坡面、坡面法向水平投影、测线方向和夹角 `beta`。可以用三维坐标图表达。
2. **坐标系与方向约定表**：在符号说明后放一张小表，列出 `r`、`beta`、`alpha_eff`、`D(r,beta)` 的含义、单位和方向。
3. **三维到二维剖面的投影图**：在推导 `alpha_eff` 时画，说明多波束扫描平面垂直于测线方向，真正进入问题一公式的是等效坡度。
4. **`alpha_eff` 随 `beta` 变化曲线**：在模型检验或结果分析中画，突出 `beta=0/180` 时等效坡度为 0，`beta=90/270` 时等效坡度达到正负最大。
5. **船位水深 `D(r,beta)` 曲线组**：以距离 `r` 为横轴，不同 `beta` 为多条曲线，解释覆盖宽度变化首先受水深影响。
6. **覆盖宽度 `W(r,beta)` 曲线组**：以距离 `r` 为横轴，不同 `beta` 为多条曲线，是结果分析中最直观的图。
7. **覆盖宽度热力图**：横轴为距离 `r`，纵轴为 `beta`，颜色为覆盖宽度，适合展示整体趋势。
8. **覆盖宽度三维曲面图**：横轴为 `r`，纵轴为 `beta`，竖轴为 `W`，适合作为问题二亮点图。
9. **特殊角度验证表**：列出 `beta=0,90,180,270` 的理论性质和程序结果现象，支撑模型正确性。
10. **候选方案比较表**：简要比较“直接套平底公式”“只修正水深”“水深+等效坡度修正”三种方案，说明最终选第三种。

这些图表都应服务于论文论证，不要为了凑数量堆放重复图。优先推荐三维坡面示意图、覆盖宽度曲线组、覆盖宽度热力图和特殊角度验证表。

## 十、注意事项

方向约定必须在论文中写清。若把坡面法向水平投影的正方向取为浅水方向，则 `beta=0` 与 `beta=180` 两行会互换；覆盖宽度模型本身不变，只是方向编号改变。
