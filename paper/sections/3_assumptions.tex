\section{模型准备}

\subsection{基本假设}

\textbf{全文通用假设：}
\begin{enumerate}
  \item 海水介质均匀，声波沿直线传播，不计折射、散射及声速剖面变化。
  \item 换能器在垂直航迹的扫描平面内对称发射，半开角为 $\phi=\theta/2$。
  \item 测量船沿设计测线稳定航行，暂不计横摇、纵摇和定位误差。
\end{enumerate}

\textbf{规则斜坡假设：}
\begin{enumerate}
  \item 问题一至三的海底为恒定小坡度平面，水深沿坡向线性变化。
  \item 相邻条带的覆盖、间距和重叠量均取水平投影。
\end{enumerate}

\textbf{真实地形假设：}
\begin{enumerate}
  \item 问题四在每个网格邻域和短距离声束作用范围内以局部线性剖面近似海底。
  \item 测线段内的覆盖能力由局部水深和垂直测线方向的坡度分量确定。
\end{enumerate}

直线传播假设使声束边界可由射线与海底剖面的交点确定；局部线性假设把真实曲面转化为可调用的斜坡覆盖关系。前者忽略的声学误差和后者在坡度突变区产生的几何误差，均在模型适用边界中讨论，并通过提高安全重叠率或原网格回代降低漏测风险。

\subsection{符号说明}

水平坐标 $x$ 指向东、$y$ 指向北，水深 $D$ 以竖直向下为正。角度输入采用角度制，进入三角函数时转换为弧度。距离、覆盖宽度和重叠量以米为主单位；海里仅用于海域范围和分带尺度，按 $1$ 海里 $=1852$ m 换算。重叠宽度 $O>0$ 表示相交，$O=0$ 表示恰好衔接，$O<0$ 表示存在缺口。

符号按物理类别区分：$d$ 只表示测线之间的水平距离，$O$ 只表示带符号的重叠宽度；$\alpha$ 表示海底坡角，$\beta$ 表示航向夹角，$\alpha_{\mathrm{eff}}$ 表示扫描剖面内的等效坡度。问题三中的东西半宽记为 $B_W,B_E$，与问题一的左右半宽 $B_L,B_R$ 含义对应；问题四的局部梯度 $g_x$ 在首次使用处定义。
